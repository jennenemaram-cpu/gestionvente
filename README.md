# Gestion Vente

Application web de gestion des ventes construite avec Next.js, React, TypeScript et Prisma.

## Démarrage

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000) dans ton navigateur.

> Les variables d'environnement et la base de données locale ne sont pas incluses dans ce dépôt.
